# Interactive To-Do List with LocalStorage

## About
A task management application developed
using HTML, CSS and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Remaining task counter
- Save tasks in LocalStorage
- Restore tasks after page refresh

## Technologies
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser LocalStorage

## How to Run
Open index.html in your browser.

## How Data Is Saved
JavaScript JSON.stringify() converts
the tasks array into text for LocalStorage.

JSON.parse() loads the saved tasks
when the application starts.
